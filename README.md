# RankMap Pro

Chrome extension for **local SEO on Google Maps** — rank checking, GBP audits, competitor scans, and no-website lead finding.

## Features

- **Lead Finder** — Find local businesses without a website on their Google Business Profile
- **Rank Check** — Drop a pin on the map and see where a business ranks for a keyword at that location
- **GBP Audit** — Score Google Business Profiles and export white-label PDF reports
- **Local Scan** — Quick and deep competitive analysis on Maps search results
- **Enrichment** — Optional email, social, and owner lookup during scans

## Setup

```bash
npm install
npm run build
```

## Load in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select the `dist` folder

## Usage

1. Click the extension icon
2. Enter **Niche**, **Location**, and **Results** count
3. Click **Find Businesses Without Websites** (or use GMB Audit / Check Rank on Google Maps listings)
4. Open **Dashboard** for scan history, settings, and overview stats

## Tech stack

- Chrome Manifest V3
- TypeScript
- React
- Vite
- @crxjs/vite-plugin

## Development

```bash
npm run dev
```

Reload the extension on `dist` after changes.
